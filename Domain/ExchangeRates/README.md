# ExchangeRates

Reusable current rates, conversion, offline snapshots, and historical series. `ExchangeRatesUI` adds currency presentation, artwork, and localized rate messages.

The core is independent of UI and app configuration. The repository-root manifest preserves standalone consumption; this package also exposes the UI product. Select one core product per executable, and preserve standalone core compatibility when changing the package.

The [core usage guide](Sources/ExchangeRates/README.md) covers standalone integration.
