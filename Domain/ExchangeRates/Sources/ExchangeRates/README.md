# ExchangeRates

Currency's rate core for Decimal currency conversion, current fiat/crypto quotes, offline snapshots, and historical series. No third-party dependencies, app identifiers, UI frameworks, or credentials.

```swift
import ExchangeRates

let store = RateStore(directory: cacheDirectory)
let result = try await store.refreshRates(using: RateService(directory: cacheDirectory))
let dollars = result.snapshot.convert(100, from: "EUR", to: "USD")

let history = HistoryService(directory: cacheDirectory)
let month = await history.load(base: "EUR", quote: "USD", range: .month)
```

Quotes are currency units per EUR. Conversion returns an unrounded `Decimal?`; callers choose display precision. Missing/invalid rates return nil. Snapshots preserve publication dates and intraday timestamps. Refresh warnings, history issues, and provenance are typed so hosts can choose their own presentation. `RateSource` contains a `RateProviderID`, `RateObservation`, optional time zone and conversion metadata; switch on these values to select your own strings or localization. Custom providers use `.custom("Provider name")`.

`RateService` uses Fawaz daily data and Coin Metrics Community crypto reference prices. `HistoryService` supplies supported 24-hour crypto charts and longer daily/monthly ranges. `RateStore` spaces automatic refresh attempts by one minute, limits manual attempts to once per ten seconds, and coalesces refreshes through a bounded lease in the host-supplied shared directory. It retains the newest successful observation after transient failures and realigns cached Coin Metrics quotes with the selected daily EUR/USD reference. Explicitly injected providers remain available for tests and custom consumers. The package does not schedule background work.

Coin Metrics supplies USD crypto reference prices. Current quotes request one latest observation per asset. Supply the same directory to rate and history services so requests share a conservative one-second spacing, bounded request lease, and persisted rate-limit cooldown. Retries honor server retry times and use bounded exponential backoff with jitter. Corrupt coordination records fail closed. Cross-crypto charts divide aligned observations; other quote currencies may use a separately dated daily Fawaz FX reference and are approximate converted reference prices. They are not intraday FX or exchange candles. Intraday availability depends on Community coverage; missing observations remain explicit.

Daily fiat ranges use at most two Frankfurter range requests, trying ECB and then CBU. Each request uses dated EUR references for the requested pair; unsupported or unavailable pairs fall back to dated Fawaz publications. Crypto and metal daily ranges use dated Fawaz observations from March 2024. Older bundled Coin Metrics crypto and selected Frankfurter fiat monthly references extend All where available. All uses bundled completed-month reference observations where available, omits the current incomplete month and fetches missing completed months when necessary. Bundled Fawaz samples use March 2, 2024 and then each completed month’s first day. These are reference observations rather than exchange closing prices. Coverage differs by currency and provider. Missing pre-listing history is not invented. History caches use a versioned pair/range key and validate source provenance and observations before reuse.

Bundled history is generated by `Scripts/History/generate_archive.py`; the resource records its source selection and sampling. Preserve the bundled licence and source notices when redistributing data. [Data sources and licences](../../../../Documentation/DataSources.md) covers Coin Metrics CC BY-NC 4.0, Fawaz CC0 and original fiat-source terms. The code’s MIT licence does not cover third-party data.
