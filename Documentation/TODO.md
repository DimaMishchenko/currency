# Backlog

[GitHub Issues](https://github.com/DimaMishchenko/currency/issues) is the project backlog. Add new tasks there instead of maintaining a separate TODO list.

[Release checks](https://github.com/DimaMishchenko/currency/issues?q=is%3Aissue+is%3Aopen+label%3Averification) use the `verification` label. They are unverified or need revalidation, not claims of current defects. Close them with a dated result and durable issue/PR evidence.
