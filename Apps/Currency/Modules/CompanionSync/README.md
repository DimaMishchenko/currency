# CompanionSync

Phone-authoritative favorites transfer through WatchConnectivity application context. The context contains the phone's source plus ordered manual destinations, a schema version, an installation identity, and a monotonically revised preference version. Amount, Watch source, and dynamic Local state remain local. Receiving favorites retains the current destination as primary when it is still included.

`CompanionSyncEngine` accepts explicit revision storage, confirmed-input mutation, and change notification operations. `CompanionSyncStateStore` atomically stores metadata in an executable-owned directory. Only absence permits a fresh identity; unreadable or incompatible metadata throws. Preferences persist before publication, and unchanged favorites reuse their revision even when the amount changes. Received revisions persist after input commits; if metadata persistence fails, retransmission safely reapplies the same preferences and retries metadata without discarding the Watch amount or source.

`CompanionSyncTransport` starts inactive. Composition chooses `.phone` or `.watch`, calls `start()` explicitly, and calls `publish(_:)` after phone preference changes. Phone publication reads confirmed input with `ConversionStore.readInput()`; unreadable or incompatible input preserves the last durable publication. Activated phone sessions flush the durable latest publication; Watch activation also consumes any received latest context. Watch foreground entry calls `reconcile()` to retry the latest received context after a transient commit failure, while committed revisions remain deduplicated. Reconciliation is inactive after `stop()`, which detaches this transport's delegate. Watch transports never publish settings. Application context coalesces to the latest preferences and does not require interactive reachability; Apple controls delivery timing.

Engine tests use injected operations and do not activate WCSession. Physical-device delivery, installation pairing changes, and reconnect behavior require native acceptance.
