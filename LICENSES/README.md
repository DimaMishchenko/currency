# Third-party data licences

These texts accompany the data described in [Data sources](../Documentation/DataSources.md):

- `CC-BY-NC-4.0.txt`: Coin Metrics Community data and Currency’s contributions to adapted Coin Metrics datasets.
- `CC-BY-4.0.txt`: covered European Commission / InforEuro material.
- `Fawaz-CC0-1.0.txt`: Fawaz Exchange API repository’s declared CC0 terms.

Other source-specific data terms and attribution statements are linked in Data sources. These data licences do not change the project source-code [MIT licence](../LICENSE), and MIT does not relicense third-party data. Retain source notices and modification metadata when redistributing datasets. Check that each distributed package preserves Creative Commons recipients’ rights, including the prohibition on additional legal restrictions and effective technological measures that restrict the licensed rights.
